قياسات المرمر: النسخة المستقلة (تعمل بدون إنترنت)
=================================================

محتويات المجلد. ارفعها كلها كما هي ولا تغيّر أسماءها:

    index.html
    manifest.webmanifest
    sw.js
    icon-192.png
    icon-512.png
    icon-maskable-512.png
    apple-touch-icon.png
    .nojekyll

(الملف .nojekyll فارغ ومطلوب. إذا لم يظهر عندك فأنشئه بنفسك كما في الخطوة 1.6)


الجزء الأول: رفع التطبيق على الإنترنت (استضافة مجانية)
-------------------------------------------------------
هذا الجزء يحتاج مرة واحدة فقط.

1.1  افتح الموقع التالي وأنشئ حساباً مجانياً:

        github.com

1.2  بعد تسجيل الدخول اضغط علامة + أعلى الصفحة، ثم اختر:

        New repository

1.3  في خانة اسم المستودع اكتب اسم المستخدم الخاص بك ثم .github.io
     مثال: إذا كان اسمك ahmad فاكتب:

        ahmad.github.io

     واختر Public، ثم اضغط Create repository.

1.4  داخل المستودع اضغط:

        Add file  ثم  Upload files

     اسحب إليه كل ملفات هذا المجلد (بعد فك الضغط)، ثم اضغط Commit changes.

1.5  افتح تبويب Settings ثم اختر Pages من القائمة الجانبية.
     تحت Source اختر:

        Deploy from a branch

     واختر الفرع main والمجلد root، ثم اضغط Save.

1.6  إذا لم يظهر الملف .nojekyll في المستودع: اضغط Add file ثم Create new file،
     واكتب الاسم  .nojekyll  وأبقِ محتواه فارغاً، ثم Commit.

1.7  بعد دقيقة أو دقيقتين يعمل التطبيق على الرابط:

        https://ahmad.github.io/

     (استبدل ahmad باسمك). افتحه في Chrome للتأكد.


الجزء الثاني: تثبيته كتطبيق على الجوال (بدون APK)
--------------------------------------------------
2.1  افتح رابطك في متصفح Chrome على الجوال وانتظر حتى تظهر الصفحة كاملة.
2.2  اضغط قائمة النقاط الثلاث ⋮ أعلى المتصفح.
2.3  اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
2.4  سيظهر التطبيق بأيقونة على شاشة الجوال.
2.5  جرّبه: شغّل وضع الطيران وافتح التطبيق من الأيقونة. يجب أن يعمل.


الجزء الثالث: تحويله إلى ملف APK
---------------------------------
3.1  افتح الموقع التالي:

        pwabuilder.com

3.2  الصق رابط تطبيقك في الخانة واضغط Start، وانتظر انتهاء الفحص.
3.3  اضغط:

        Package for stores

     ثم اختر Android، ثم اضغط Generate Package.
3.4  في خيارات الحزمة اكتب:

        Package ID:  com.elora.qiyasat
        App name:    قياسات المرمر

     وفي خانة Signing key اختر New ليصنع مفتاح توقيع جديداً.
3.5  حمّل الملف المضغوط الناتج. بداخله:
        - ملف بامتداد .apk وهو التطبيق الذي تثبته على الجوال.
        - ملف مفتاح التوقيع مع كلمات السر.
     احتفظ بالمفتاح وكلمات السر في مكان آمن. بدونها لا تستطيع تحديث التطبيق لاحقاً.
3.6  انقل ملف الـAPK إلى الجوال وافتحه. وافق على «التثبيت من مصادر غير معروفة» عند طلبه.


الجزء الرابع: إخفاء شريط العنوان في الـAPK (اختياري)
-----------------------------------------------------
داخل الملف المضغوط من PWABuilder ملف اسمه:

        assetlinks.json

4.1  في مستودع GitHub اضغط Add file ثم Create new file.
4.2  اكتب مسار الملف بالضبط:

        .well-known/assetlinks.json

4.3  الصق داخله محتوى ملف assetlinks.json كما هو، ثم Commit.
4.4  بعد دقيقة افتح الرابط التالي وتأكد أن المحتوى يظهر:

        https://ahmad.github.io/.well-known/assetlinks.json

بدون هذا الجزء يعمل التطبيق بشكل سليم لكن يظهر شريط عنوان صغير أعلى الشاشة.


ملاحظات
-------
- افتح التطبيق مرة واحدة مع الإنترنت بعد التثبيت، ثم يعمل بدون إنترنت.
- الخطوط تُحمَّل في أول فتح مع الإنترنت ثم تُحفظ على الجوال.
- القياسات المحفوظة تُخزَّن داخل Chrome على الجوال. مسح بيانات Chrome يحذفها، لذلك صدّر الـPDF لكل قياس.
- زر «مشاركة» يفتح قائمة الجوال لإرسال الملف بالواتساب. زر «حفظ PDF» يحفظه في التنزيلات.
- يحتاج الـAPK أن يكون متصفح Chrome مثبتاً على الجوال.
- لتحديث التطبيق لاحقاً: غيّر رقم النسخة داخل sw.js (مثلاً من qiyasat-v6 إلى qiyasat-v7) وارفع الملفات من جديد.
